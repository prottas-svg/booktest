# v6.1 — edition discovery + diagnostics

This build combines the v6.0 edition-discovery lookup improvement with the v5.10 diagnostic tracing.

## Lookup behavior
- Preserves the existing exact-ISBN and `isbn_search_unique` success path.
- Adds strict bibliographic edition discovery using Open Library and Google Books.
- Candidate editions are not trusted automatically; each candidate must independently return an AR result from AR Bookfinder.
- Previously unresolved books receive a one-time release recheck under v6.1.

## Verification diagnostics
The server verification dashboard now records:
- title/author metadata used,
- exact ISBN attempt,
- ISBN-10/equivalent attempt,
- quick-search attempt,
- strict title+author attempt,
- related-edition candidates and results,
- final error or rejection reason.

These diagnostics are server/admin-only and do not themselves modify user libraries.
