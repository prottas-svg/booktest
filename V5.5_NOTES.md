# My AR Shelf v5.5

Server-side verification release.

- Automatically rechecks backed-up unresolved ISBNs once per server release.
- Maintains a persistent regression set from every observed successful AR lookup.
- Rechecks known-good ISBNs on each release and flags regressions.
- Separates immediate server verification from client repair after a user returns.
- Adds a manual **Run server verification** control to `/admin`.
- Does not overwrite user libraries during server verification.
- Does not change AR matching logic.
