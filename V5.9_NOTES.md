# My AR Shelf v5.9 — Admin analytics cleanup

Server/dashboard-only release.

- Refresh now visibly shows **Refreshing…**, then **Updated ✓**, plus a last-updated time.
- Manual refresh uses `cache: no-store` and preserves the selected client-version filter.
- `server_verification` events are excluded from user-facing product metrics, funnels, behavior, reliability, book quality, and recent sessions.
- Server events remain available in **Fix verification**.
- A prior completed verification is labeled as such while a new run is active.
- The just-finished server run is promoted immediately from the verification API state, avoiding a stale older release header.
- No lookup/scanning/client-data behavior changes.
